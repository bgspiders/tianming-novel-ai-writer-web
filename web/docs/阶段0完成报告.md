## 四、Troubleshooting

| 现象 | 排查 |
|------|------|
| `dotnet --version` 报 command not found | 新开终端，或手动加入 PATH `export PATH="/usr/local/share/dotnet:$PATH"` |
| `dotnet restore` 慢 | 加国内镜像 `dotnet nuget add source https://nuget.cdn.azure.cn/v3/index.json -n cdn` |
| 前端 npm install 装不上 | 已在 `web/frontend/.npmrc` 配置了 registry，如仍失败可改为 `https://registry.npmmirror.com` |
| `/api/health` 报 CORS | 确认前端跑在 38720，后端 [Program.cs](../backend/src/TM.Web.Api/Program.cs) 的 CORS 白名单包含 `http://localhost:38720` |
| SignalR 连不上 | 检查 [vite.config.ts](../frontend/vite.config.ts) 中 `/hubs` 代理的 `ws: true` 是否生效 |
| AI 调用 401 / 403 | 检查 endpoint 是否正确（OpenAI 是 `/v1`，部分国内兼容服务是 `/v1/chat/completions` 的父路径）；检查 API Key |
| AI 调用 connection refused | 检查代理设置；该应用使用直连，不走系统代理 |
| Docker build 失败 | 阶段 0 镜像基于 `mcr.microsoft.com/dotnet/aspnet:8.0`，确保 docker 可访问 mcr 镜像 |
