## 三、关键技术决策

1. **LegacyBridge 不一次性源码包含 Services**：原 Services 261 cs 文件依赖 `TM.App.Log`（972 处）、`TM.Framework.UI.Workspace.*`、`TM.Modules.*` 等 50+ 个 WPF/UI 命名空间。一次拉入需补 50+ 个 stub 类，单会话风险高。改为分两步：本次只放替身骨架，下次按模块逐个 `<Compile Include>` 并补缺。
2. **数据导入不走 Services**：直接 `System.Text.Json` 反序列化为 DTO + EF upsert，避免引入 Services 复杂依赖。代价是字段映射要手写一份（已通过 `LegacyCategoryDto` / `LegacyPromptTemplateDto` 等 record 完成）。
3. **GenerationProgressHub 直接改原文件**：仅 14 行，加 `IProgressSink` + `AsyncLocal<RunId>` 后保持向后兼容 WPF。比 partial class 适配更直观。
4. **AES-GCM 选型**：12 字节 nonce + 16 字节 tag，密文用 `cipher + tag` 拼接存到 `EncryptedKey` BLOB 列，`Iv` 列单存 nonce。`File.SetUnixFileMode(UserRead | UserWrite)` 等效 chmod 0600。
5. **内置 Provider 不可删除**：`IsBuiltIn` 字段保护，UI 仅允许禁用。代码与 UI 双重校验。
6. **轮换策略**：`RotateNextPlainKeyAsync` 按 `LastUsedAt` 升序选最久未用、同序号取 `RotationOrder` 升序，命中后更新 `LastUsedAt`。简单 LRU。
7. **Endpoint 自动补 /v1**：跟阶段 0 `AiCompletionService.NormalizeEndpoint` 一致逻辑，避免用户填 `https://api.openai.com` 触发 404。
