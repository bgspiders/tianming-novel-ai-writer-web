# 生成模块优化开发计划

本文档用于追踪生成模块的本地开发计划和完成情况。当前目标不是一次性重写整站，而是在现有 Vue 3 + ASP.NET Core + SQLite 架构上，把长篇生成链路逐步改造成可预检、可分段、可持久化、可暂停、可回写的稳定流程。

## 1. 已完成

### 1.1 生成前预检

- 新增后端接口：`POST /api/generation/preflight`
- 新增持久化表：`generation_preflight_reports`
- 当前检查项：
  - 项目是否存在
  - 分卷是否存在
  - 章节是否存在
  - 章节计划是否存在
  - 章节蓝图/场景卡是否存在
- 前端入口：章节生成页的“生成流程控制 / 生成前预检”

### 1.2 场景级生成

- 新增后端接口：`POST /api/generation/chapters/{chapterId}/scene-draft`
- 新增持久化表：`scene_generation_records`
- 当前能力：
  - 按章节蓝图的 `SceneNumber` 生成单个场景
  - Prompt 中注入当前章节和当前场景蓝图
  - 保存场景正文、Prompt 快照、模型、耗时、成功/失败状态
- 前端入口：章节生成页的“生成场景”

### 1.3 场景合成章节

- 新增后端接口：`POST /api/generation/chapters/{chapterId}/scene-compose`
- 当前能力：
  - 读取当前章节下最新成功场景记录
  - 按 `SceneNumber` 排序合成完整正文
  - 保存到章节正文文件并更新章节字数和状态
- 前端入口：章节生成页的“合成正文”

### 1.4 生成后基础分析

- 新增后端接口：`POST /api/generation/chapters/{chapterId}/analysis`
- 新增持久化表：`chapter_analysis_reports`
- 当前检查项：
  - 正文字数是否低于阈值
  - 近章标题是否重复
  - 生成基础质量分、连贯分、是否建议暂停批量任务
- 前端入口：章节生成页的“生成后分析”

### 1.5 批量任务数据库持久化

- 新增持久化表：`chapter_batch_generation_jobs`
- 新增持久化表：`chapter_batch_generation_job_logs`
- 当前能力：
  - 批量任务入队时写入数据库
  - 后台运行时持续刷新状态、进度、当前章节、取消标记
  - 后台日志写入数据库，刷新页面后仍可查看最近任务
  - 内存中的运行任务和数据库中的历史任务会合并返回

### 1.6 批量生成刹车条件

- 当前能力：
  - 每章正文生成后自动调用章节分析
  - 若分析结果 `ShouldPauseBatch = true`，自动请求取消后续批量生成
  - 失败、跳过、完成、暂停原因会同步写入任务记录和日志

### 1.7 AI 开书分步工作流基础版

- 新增后端接口：
  - `POST /api/novel-seed/workflows`
  - `GET /api/novel-seed/workflows/{workflowId}`
  - `POST /api/novel-seed/workflows/{workflowId}/steps/{stepKey}/run`
- 新增持久化表：
  - `novel_seed_workflows`
  - `novel_seed_workflow_steps`
- 当前步骤：
  - `story`：整书压缩故事
  - `metadata`：核心种子与小说元信息
  - `volumes`：分卷蓝图
  - `chapters`：前期章节卡
  - `finalize`：调用现有开书服务落库生成项目
- 前端入口：AI 开书页新增“分步开书”和步骤运行面板

### 1.8 完整上下文装配基础版

- 新增运行时 DTO：
  - `GenerationContextRequest`
  - `GenerationContextResult`
  - `GenerationContextSectionDto`
- 扩展后端服务：`IContextPackagingService.BuildGenerationContextAsync`
- 当前装配层级：
  - P0：当前章节、章节计划、当前场景蓝图
  - P1：当前卷目标、最近章节摘要、角色追踪状态、角色规则
  - P2：未回收伏笔、近期时间线
  - P3：世界硬规则、创意素材/文风参考
- 已接入链路：
  - 整章正文生成 Prompt
  - 场景级生成 Prompt

### 1.9 AI 开书分步工作流历史管理

- 新增后端接口：
  - `GET /api/novel-seed/workflows`
  - `DELETE /api/novel-seed/workflows/{workflowId}`
- 当前能力：
  - 刷新页面后可重新加载最近分步开书工作流
  - 可打开历史工作流继续运行后续步骤
  - 可删除不需要的分步开书记录及其步骤
- 前端入口：AI 开书页的“分步开书工作流”历史列表

### 1.10 Prompt 与生成记录版本化基础版

- 新增持久化表：`prompt_run_snapshots`
- 当前记录字段：
  - RunId、项目、章节、工作流、步骤、来源
  - 模型、温度、最大 Tokens
  - 上下文 hash、上下文摘要、Prompt 摘要、输出摘要
  - 成功状态、错误、耗时
- 已接入链路：
  - 场景级生成
  - 整章正文生成
  - AI 开书分步工作流步骤

### 1.11 AI 开书分步产物直接落库

- `NovelSeedService` 提供从已解析规划 JSON 直接落库的内部入口。
- 分步开书 `finalize` 步骤会优先从已完成步骤输出中提取 JSON 规划并直接创建项目。
- 若步骤产物没有可解析 JSON，仍保留旧的完整开书生成兜底。

### 1.12 上下文装配增强

- P1 上下文增加上一章正文结尾片段。
- 上下文包产生稳定 SHA256 hash，并写入 Prompt 运行快照。

### 1.13 标题和简介去重增强

- 章节计划批量重写会自动处理重复标题。
- 重写后的章节简介会按章节号、标题和实体组合生成差异，避免连续章节简介高度一致。
- 前端按钮文案更新为“批量重写标题/简介”。

### 1.14 完整生成流程页基础版

- 生成工作台改为流程式入口，串起：
  - AI 开书
  - 五件套绑定
  - 大纲/规划
  - 章节计划
  - 章节蓝图
  - 生成预检
  - 场景/正文
  - 体检
  - 存档/打包

### 1.15 AI 开书分步工作流增强

- 分步开书步骤新增 `IsConfirmed` 人工确认状态。
- 新增后端接口：`POST /api/novel-seed/workflows/{workflowId}/steps/{stepKey}/confirm`
- 只有已完成步骤允许确认，重新运行步骤会自动取消确认。
- 前端步骤面板显示“已确认/待确认”，并提供“确认产物/取消确认”按钮。
- 已补充单元测试覆盖完成步骤确认和未完成步骤禁止确认。

### 1.16 Prompt 运行快照查询与查看

- 新增后端接口：
  - `GET /api/generation/prompt-snapshots`
  - `GET /api/generation/prompt-snapshots/{id}`
- 支持按项目、章节、工作流筛选，并限制返回数量。
- 前端生成工作台新增“Prompt 运行快照”面板，可查看最近快照和详情抽屉。

### 1.17 完整生成流程页状态化

- 新增后端接口：`GET /api/generation/flow-status?projectId=...`
- 当前状态统计覆盖：
  - AI 开书项目绑定
  - 五件套/设定资料数量
  - 大纲/分卷规划数量
  - 章节计划数量
  - 章节蓝图数量
  - 正文章节完成数量
  - 体检记录数量
  - 存档/上下文打包数量
- 前端生成工作台改为读取当前项目状态，显示每一步数量、最近更新时间、下一步建议和最近错误。

### 1.18 自动生成前同质化阻断

- 批量正文生成入队前会检查 `PreviewItems`。
- 若连续批量预览里出现严重重复标题、重复简介或相邻简介高度相似，直接阻断入队。
- 错误提示会要求先批量重写标题/简介，确认预览后再启动自动生成。
- 已补充单元测试覆盖严重同质化预览阻断。

### 1.19 上下文装配规则增强

- P2 上下文增加从五件套 `archive_events` 中抽取的锁定事实/档案事件提示。
- P2 上下文接入 `IChapterRecallService` 的相关记忆 Top-K 召回，召回查询由章节计划、场景蓝图、实体、地点、伏笔关键词组合生成。
- Top-K 召回结果以“章节摘要 + 命中关键词 + 召回原因”的形式进入上下文，避免注入整段历史正文。
- P3 上下文增加：
  - `generation.*` / `platform.*` AppSettings 中的生成模式与平台规则
  - 五件套 `world_rules` 世界观规则
  - 五件套 `style_sample` 文风样本
- 当前已接入结构化资料、五件套 Markdown 内容、设置项和章节召回 Top-K。

### 1.20 AI 开书分步结构化预览与片段重写

- 新增后端接口：
  - `GET /api/novel-seed/workflows/{workflowId}/steps/{stepKey}/preview`
  - `POST /api/novel-seed/workflows/{workflowId}/steps/{stepKey}/rewrite`
- 支持从步骤输出中解析结构化片段：
  - `volumes`：分卷数组
  - `chapters`：章节卡数组
  - 其他 JSON 对象：按顶层字段预览
  - Markdown 输出：按标题/列表行生成兜底预览
- 支持对单个片段发起 AI 重写，并替换回原步骤产物。
- 重写后自动取消步骤确认状态，并记录 Prompt 运行快照。
- 前端 AI 开书页新增“结构化预览”和“重写片段”入口。

### 1.21 更严格的生成后分析

- 生成后分析新增检查项：
  - `scene_blueprint_not_grounded`：场景蓝图关键锚点没有落地
  - `locked_fact_missing`：五件套档案事件里的锁定事实没有覆盖
  - `repeated_paragraph`：正文存在重复段落
  - `ending_hook_missing`：章末缺少悬念、反差或新信息钩子
- 场景蓝图缺失和锁定事实缺失为 fatal，会触发批量任务暂停。
- 重复段落和章末钩子为 warning，会降低质量分并进入分析报告。
- 已补充单元测试覆盖新增检查项。

## 2. 未完成

当前《生成模块优化开发计划》列出的本轮功能项已完成。后续可选增强不计入本轮未完成范围。

### 2.1 向量库深度集成

目标：

- 当前 Top-K 已走 `IChapterRecallService`，可继续扩展到 ChromaDB 持久向量集合。
- 增加章节原文位置锚点、场景级分片和文风样本向量集合。

### 2.2 AI 开书结构化编辑器

目标：

- 当前已支持结构化预览和单片段重写；后续可做可编辑表格、字段级保存和 diff 审核。

### 2.3 生成后 AI 语义分析

目标：

- 当前已实现规则型分析；后续可增加 AI JSON 分析，提取角色状态变化、关系变化、伏笔生命周期和职业/等级变化。

## 3. 当前继续开发顺序

本轮计划已完成，下一阶段建议顺序：

1. ChromaDB 向量库深度集成。
2. AI 开书结构化编辑器与 diff 审核。
3. 生成后 AI 语义分析与状态回写。
