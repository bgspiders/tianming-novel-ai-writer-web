## 四、关键技术决策记录

1. **表名 snake_case，列名 PascalCase**：表名通过 `ToTable("xxx")` 显式声明以匹配数据模型映射文档；列名用 EF 默认（=属性名）减少配置量。
2. **JSON 列方案**：SQLite 无原生 JSON 类型，用 `TEXT` + `ValueConverter`。`List<string>` 与 `Dictionary<string,int>` 的 ValueConverter Lambda 用静态辅助方法（避免表达式树不支持 `??`）。
3. **主键统一字符串（GUID）**：沿用原 WPF 项目的 `Id` 习惯，方便阶段 1 后半段的 JSON → SQLite 导入工具按 Id upsert。
4. **EntityBase.UpdatedAt 自动维护**：在 `AppDbContext.SaveChanges` 重写中遍历 `ChangeTracker.Entries<EntityBase>()` 自动写入 `UpdatedAt`。
5. **VolumeFactArchive.SnapshotPayload 直接 JSON 字符串**：12 维事实快照整体作为 JSON 列入库，不拆子表 —— 卷归档本身就是"冻结快照"，不需要按字段查询。
6. **Foreshadowing.OverdueSuggestion 字段**：新增字段（原 JSON 模型分两个类 PendingForeshadowing/OverdueForeshadowing），合并到一张表 + 状态字段。
7. **CharacterStateEntry.CharacterId 不做外键**：原 Guide 中可能有 AI 临时生成的次要角色没有 CharacterRule 记录；只做索引不强约束。
8. **Application.csproj 包版本清理**：SemanticKernel 1.73 链路里的 `Microsoft.Extensions.AI 10.3.0` 要求 `Microsoft.Extensions.DependencyInjection.Abstractions >= 10.0.3`，而阶段 0 显式写了 8.0.2 触发 NU1605。本阶段删除显式版本，让传递依赖生效。
