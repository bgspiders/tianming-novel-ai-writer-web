# 生成操作简化并行开发计划

## 目标

当前生成相关入口过多，用户需要在 AI 开书、天命协议、大纲、卷设计、章节计划、章节蓝图、章节生成、叙事追踪、生成闸门之间来回跳转。此次改造目标是把生成体验收敛成更清晰的闭环：

1. 减少侧边栏入口，让用户优先看到最常用路径。
2. 把规划类页面聚合到一个入口，避免大纲、卷设计、章节计划、章节蓝图分散。
3. 让生成工作台提供“继续下一步”的主按钮，用户不用判断下一步该点哪里。
4. 章节生成页默认展示自动连续生成的核心能力，单章精写和高级细节保留但不抢首屏。
5. 旧路由继续可访问或跳转，避免历史链接、按钮和新手引导失效。

## 简化后的主入口

### 1. AI 开书

路径：`/generate/novel-seed`

用于从描述创建整书素材，包含整书压缩故事、核心种子、小说元信息、分卷蓝图、前期章节卡、伏笔账本和时间线。保留 Agent 分步运行，但入口名称保持简单。

### 2. 规划

路径：`/generate/planning`

聚合原有：

- 大纲：`/generate/outlines`
- 卷设计：`/generate/volume_designs`
- 章节计划：`/generate/chapter_plans`
- 章节蓝图：`/generate/chapter_blueprints`

页面内用标签切换。旧路径保留重定向或继续落到对应模块，避免破坏已有链接。

### 3. 写正文

路径：`/generate/chapters`

默认进入“自动连续生成”模式。首屏只保留项目/卷、起始章、生成章数、是否补齐缺失章节、是否失败暂停、启动后台任务、进度和日志。单章精写、场景正文、预检详情、AI 参数放入高级折叠区。

### 4. 追踪与体检

路径优先保留：`/generate/tracking`

用于查看和重建伏笔、时间线。校验中心保留为独立能力，但菜单文字和工作台文案要表达它属于生成后的追踪/体检闭环。

### 5. 工作台

路径：`/generate`

工作台不再只是卡片导航，而是展示当前项目状态、下一步建议和一个主按钮。卡片仍保留为辅助入口。

## 并行任务拆分

### 任务 A：菜单与路由简化

写入范围：

- `frontend/src/layouts/MainLayout.vue`
- `frontend/src/router/index.ts`
- `frontend/src/i18n/messages.ts`
- 必要时同步 `frontend/src/i18n/messages.js`

要求：

- 侧边栏生成菜单精简为：工作台、AI 开书、规划、写正文、追踪与体检。
- 设计模块菜单只保留设定类入口，不再重复展示规划类入口。
- 新增 `/generate/planning` 路由。
- 旧生成规划路由继续可用。

### 任务 B：规划聚合页

写入范围：

- 新增或修改 `frontend/src/views/generate/PlanningWorkspaceView.vue`

要求：

- 页面内用标签展示大纲、卷设计、章节计划、章节蓝图。
- 根据当前标签复用现有 `DesignView` 的模块能力。
- 支持从 query 或默认值定位到章节计划、章节蓝图等模块。

### 任务 C：章节生成页简化

写入范围：

- `frontend/src/views/generate/ChapterGenerationView.vue`
- 必要时同步对应生成的 `.js` 文件

要求：

- 默认打开批量连续生成。
- 将单章精写、场景生成、预检详情和高级 AI 参数折叠。
- 保留现有按钮、日志、预览、确认、取消任务能力。
- 小屏幕下顶部控件不能拥挤。

### 任务 D：工作台继续下一步

写入范围：

- `frontend/src/views/generate/GenerationWorkbenchView.vue`
- 必要时同步对应生成的 `.js` 文件

要求：

- 根据 `flowStatus.nextSuggestion` 和步骤状态计算下一步。
- 顶部增加一个主按钮“继续下一步”。
- 卡片区保留，但优先突出当前建议步骤。
- 没选项目时主按钮提示先选择或创建项目。

## 验证

完成后至少执行：

```bash
npm --prefix frontend run type-check -- --noEmit
npm --prefix frontend run build
```

如果涉及后端接口或数据模型，再执行：

```bash
dotnet test backend/tests/TM.Web.Tests/TM.Web.Tests.csproj
```
